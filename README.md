# Amazon-Sales-Analysis

# Project Description
Amazon Sales data analysis using python(Pandas,Matplotlip,Seaborn)with data cleaning and visualization

## 📊 Tools Used
- Python (Pandas, Matplotlib, Seaborn)

## 🧹 Data Cleaning
- Removed duplicate values
- Handled missing values
- Fixed text formatting using strip()

## 🔍 Data Analysis (EDA)
- Category-wise sales
- Price vs Quantity analysis
- Monthly sales trend
- Outlier detection (Boxplot)

## 📈 Visualizations
- Bar chart (Category-wise sales)
- Box plot (Outliers)
- Heatmap (Correlation)
- Price distribution

## 💡 Key Insights
- Top selling category identified
- Sales trend varies by month
- Price impacts total sales

## 📌 Conclusion
This project analyzes Amazon sales data using Python and visualizes insights using charts.
